# Knight's Tour

An interactive visualization of the Knight's Tour problem. Move the knight manually or watch a backtracking solver use Warnsdorff's heuristic to find a tour of the 8×8 chessboard.

## Features

- Choose a starting square and make legal knight moves.
- See visited squares, move numbers, and available moves on the board.
- Animate an automatically generated tour and adjust its speed.
- Track progress across all 64 squares.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
